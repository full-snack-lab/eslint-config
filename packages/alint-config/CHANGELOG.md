# Changelog

All notable changes to `@fullsnacklab/alint-config` are documented here.

## [0.1.0] — 2026-09-26

### Added

- Initial warning-level JavaScript and TypeScript preset built on
  `@alint-js/plugin-js`.
- Shared ignores for dependencies, build output, generated declarations,
  agent metadata, and test fixtures.
- Git-aware file selection and a publishable plugin with a `recommended`
  preset.
